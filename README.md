# bibek-bhattarai.vercel.app

Personal portfolio of Bibek Bhattarai — Data Science & Civil Engineering student at Arkansas State University.

**Live:** https://bibek-bhattarai.vercel.app

- `index.html` — the whole site: hand-written HTML/CSS/JS, no build step.
  The hero figure is a Warren truss drawn on a 2D canvas with a simple perspective projection;
  its deflection under a moving point load follows simply-supported beam theory.
- `work/<project>/` — case-study pages, generated by `python tools/build_cases.py` (edit the content there).
- `assets/` — shared stylesheet and script used by every page.
- `img/` — project screenshots (WebP, with 720px variants for phones); `img/case/` for case studies.
- `cv/` — the **Request CV** page. The CV is never public: visitors send a request, I get an email with an
  Approve button, and approving creates a download link that expires after 7 days.
- `api/` — Vercel functions for that flow (`cv-request`, `cv-approve`, `cv-download`). Links are AES-GCM sealed tokens,
  so no database is needed.
- `private/cv.pdf.enc` — the CV, encrypted. Update it with `node tools/encrypt-cv.mjs` (reads `CV_FILE_KEY` from `.env.local`).
- `tools/cv/` — generates the CV as a Word file (`npm install && npm run build`), then export it to PDF from Word.

Environment variables (Vercel → Settings → Environment Variables): `CV_TOKEN_KEY`, `CV_FILE_KEY`
(32 random bytes, base64), `RESEND_API_KEY` (email), optional `RESEND_FROM` (verified sender, emails the link to the
requester directly) and `CV_OWNER_EMAIL`.

Pushing to `main` deploys to Vercel automatically.
