Overview

The brief

TBN Store sells sweaters, tracksuits and matching outfit sets for kids. It serves customers who may prefer Nepali, and it confirms every order by phone, for sizing and delivery, before anything is paid.

So the site needed to feel like a real shop, with search, categories, reviews and wishlists, without forcing a card checkout that didn't match how the business works.

Approach

What I built

  1. Book now, confirm by phone

    Instead of a payment checkout, customers book the items they like, and the store calls to confirm size and delivery. The flow matches how orders are actually fulfilled.

  2. A complete catalog

    Categories, trending items, search and sorting, product pages with image galleries and a size guide, plus reviews and wishlists.

  3. Bilingual by design

    English and Nepali (नेपाली) with a one-tap toggle. Translations live in the database, so the owner can edit them without touching code.

  4. Tools that drive repeat sales

    Coupons, referral codes and back-in-stock notifications, with transactional emails sent through Resend.

  5. An admin dashboard

    Manage products, images, categories, stock, bookings, coupons and site settings in one place.

Decisions

Key decisions

Relational data model

Thirteen Prisma models (users, products, images, bookings, coupons, reviews, wishlists, referrals, translations and more) keep the business rules in the database, not scattered through pages.

Built to be found

Generated sitemap, robots rules and per-page Open Graph images, so products look right when shared on social media.

Prices in rupees, mobile first

Prices are in rupees and the layout is designed phone-first.

Safe deploys

Database migrations run as part of every production build, so the schema and the code never drift apart.

Next

What I'd do next

Add online payment as an option alongside booking, and a simple sales dashboard so the owner can see which products and sizes sell best.
