Overview

The problem

Beginners usually hit two walls: installing Python before writing a single line, and lessons that pack several new ideas into one step.

PyQuest removes both. Every lesson opens next to a code editor that runs real Python in the browser, and every lesson teaches exactly one idea.

Approach

How it works

  1. One idea per lesson

    The first version had 21 lessons. Testing showed they moved too fast, so I rebuilt the course as 83 micro-lessons in 12 modules. Each has a short explanation, two worked examples, starter code that needs one small change, and a checked answer.

  2. A second track for data

    An 18-lesson Data Scientist track covers NumPy, pandas and Matplotlib.

  3. Verified content

    A script runs every lesson's solution through real Python, so no lesson ships with a broken answer.

  4. Accounts and progress

    Email sign-up, saved progress and an admin dashboard to approve learners and see how far each one has got.

Decisions

Key decisions

Python in a Web Worker

The Pyodide runtime runs off the main thread, so the page never freezes, and a 12-second timeout restarts the worker if a learner writes an infinite loop.

Solutions stay on the server

Learners can request a lesson's full solution and an admin grants it. The answer is never sent to a browser that isn't allowed to see it.

A tutor that won't give it away

An optional AI tutor sees the lesson, the learner's code and their last error, gives hints only, and has a daily cap per learner.

Privacy-safe password reset

Reset requests always get the same reply, so the form can't be used to find out who has an account.

Results

Where it stands
