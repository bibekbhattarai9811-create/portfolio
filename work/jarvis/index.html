JARVIS

An Iron-Man-style assistant on Claude that runs on my PC, my phone and smart glasses, built to be useful and safe rather than just a demo.

Overview

The idea

I wanted a real JARVIS: something I can talk to from across the room, that answers with live information, controls my PC from my phone, and is fun to use.

It grew into one self-hosted Next.js app with four parts: a voice assistant, a hand-tracked hologram playground, a camera-based inspection tool, and a hands-free field-report demo, all reachable from a PC, a phone or a smart-glasses display.

Approach

What it does

  1. Talk to it

    Say "Jarvis" and speak. Common commands (media, timers, opening apps and sites) run instantly, in about 0.3 seconds; everything else goes to Claude with live web search. It answers out loud in a British voice.

  2. Control the PC from the phone

    Opening apps, media keys and locking the screen run on the PC itself, so the phone becomes a remote. Apps come from an allowlist and shells are blocked.

  3. HOLO

    The camera tracks both hands with MediaPipe. Pinch to grab a hologram, throw it, stretch it with two hands, or smash two together into a blast. It can also cut a real object out of the camera view and turn it into a hologram.

  4. Inspect Pro

    Photograph each room of a rental and Claude's vision model writes the report: a condition score, issues marked on the photo, safety alerts and a move-in vs move-out comparison, exported as a branded PDF with signatures.

  5. Smart glasses

    A heads-up display designed for Meta Ray-Ban Display glasses shows the latest inspection or field step; I tested it in a built-in simulator.

  6. Field Assist demo

    Dictate notes and get a first-person report draft that lists missing facts instead of inventing them, plus a scene diagram, two-way translation and checklists.

Decisions

Key decisions

Security from the start

An owner PIN and separate guest codes, lockouts after failed attempts, signed cookies, an app allowlist, and images analysed with tools disabled to block prompt injection. It passed 20 out of 20 attack tests.

Some things I chose not to build

Field Assist deliberately has no face recognition or licence-plate lookups of the public, for accuracy, legal and civil-rights reasons.

Face recognition only for greetings

It can recognise my face to say hello, but never uses it to unlock anything, because a photo can fool it.

Tested and shareable

25 automated tests and GitHub Actions run type checks, tests and a build on every push, and a public read-only demo runs on sample data.
